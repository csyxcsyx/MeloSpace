# MeloSpace 核心社区闭环升级记录

更新日期：2026-07-29

## 1. 本轮范围

本轮完成“搜索内容 → 进入详情 → 评论互动 → 查看创作者 → 收藏/管理歌单 → 社区发现”的核心闭环，同时保留原有 Apple Music 式留白、红色品牌色和克制的玻璃材质。

已实现：

- 综合搜索歌曲、歌手、专辑、公开歌单和用户，支持建议、分页、相关性排序、关键词高亮与本地最近搜索。
- 用户公开资料、头像/歌单封面上传和隐私字段隔离。
- 歌曲与公开歌单共用评论线程，支持回复、点赞、软删除、举报、管理隐藏/恢复和置顶。
- 歌单标签、资料编辑、公开性、收藏、分享、播放计数、歌单内搜索/排序、批量增删和跨端排序。
- 社区发现页的每日歌曲、热门歌单、最新歌单和真实近期热评。
- “我的音乐”个人资料卡和创建歌单、收藏、最近播放、账户四个服务端分页分区。

本轮未加入关注流、私信、通知、动态发布、实时协作歌单、Redis、Elasticsearch 或 WebSocket。

## 2. 主要接口

### 搜索与公开资料

|方法|路径|说明|
|-|-|-|
|GET|`/api/search`|综合搜索，保留原有字段并增加用户与各类型总数|
|GET|`/api/search/suggestions`|搜索建议|
|GET|`/api/search/{songs\|artists\|albums\|playlists\|users}`|分类分页搜索|
|GET|`/api/users/{id}`|只返回可公开的用户资料与统计|
|GET|`/api/users/{id}/playlists`|用户公开歌单|
|PUT|`/api/users/me`|更新当前用户资料|
|POST|`/api/uploads/images?purpose=...`|上传头像或歌单封面|

### 评论

|方法|路径|说明|
|-|-|-|
|GET|`/api/comments`|歌曲/歌单根评论，支持最新与热门排序|
|GET|`/api/comments/{id}/replies`|一级回复|
|PUT / DELETE|`/api/comments/{id}/like`|点赞/取消点赞|
|POST|`/api/comments/{id}/reports`|举报评论|
|GET|`/api/admin/comment-reports`|管理员查看举报|
|PATCH|`/api/admin/comments/{id}`|隐藏、恢复、置顶、取消置顶|

评论为纯文本，最多 500 字；每用户每分钟最多 5 条；举报每天最多 10 次，同一评论不可重复举报。

### 歌单与社区发现

|方法|路径|说明|
|-|-|-|
|POST|`/api/playlists/{id}/play`|原子增加歌单播放量|
|POST / DELETE|`/api/playlists/{id}/songs/batch`|批量添加/移除歌曲|
|GET|`/api/favorites/status`|批量查询收藏状态|
|GET|`/api/discover/community`|热门歌单、最新歌单与近期热评聚合|

热门歌单得分为 `收藏数 × 4 + 根评论数 × 3 + 播放量`；热门评论得分为 `点赞数 × 3 + 回复数 × 2`。聚合接口会过滤私有歌单、下架歌曲、隐藏和删除评论。

## 3. 数据库

数据库由 Flyway 管理，生产环境首次接入时 baseline 到 V1，后续只执行增量迁移：

|版本|内容|
|-|-|
|V1|完整基线结构|
|V2|用户简介与公开资料能力|
|V3|评论回复、点赞、举报、置顶和软删除|
|V4|`playlist_tag` 与歌单热度、收藏目标组合索引|

V4 上线前在生产结构副本验证成功：Flyway 状态为 `4:1`，迁移前后用户 10、歌曲 489、歌单 3、收藏 2、评论 1，数据量完全一致。临时数据库和临时授权在验证后删除。

歌单转为私有时，在同一事务中删除其他用户对该歌单的收藏并将 `favorite_count` 重算为 0；评论数据保留，但私有期间不对外展示。

## 4. 权限与隐私

- 公开 GET、认证入口、健康检查和媒体资源显式放行。
- 歌单公开播放计数允许匿名调用；其余 `/api/**` 默认要求登录。
- 私有歌单只允许创建者访问和管理。
- 公开资料不返回用户名、角色、状态等账号字段。
- 所有歌单管理操作以后端 `canManage` 与所有权校验为准，前端不单独决定权限。

## 8. 答辩演示流程

1. 打开发现页，介绍每日歌曲、热门/最新歌单和近期热评的真实排序。
2. 搜索歌曲、歌手、歌单和用户，演示建议、分类分页和公开主页。
3. 进入歌曲详情，发布评论、回复并点赞；管理员页展示举报与隐藏/恢复。
4. 创建公开歌单，编辑简介、标签和封面，批量添加歌曲。
5. 桌面拖拽排序；切换手机宽度后用上下移动按钮排序。
6. 使用第二个账号收藏歌单，展示收藏数和“我的音乐”服务端分页分区。
7. 将歌单改为私有，验证其他账号无法访问、收藏归零、评论重新公开后仍保留。
8. 展示 Actuator、Flyway V4、部署备份目录和当前 Git 版本。
